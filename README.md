# Hypixel SkyBlock swords catalog

This is a manually compiled list of (maybe) all the **sword-like weapons** in hypixel skyblock, used to restore the object recognition of the minecraft 1.7 version's sword blockhit animation in project [Baity](https://github.com/raueyhs/Baity).
